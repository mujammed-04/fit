# Тренировка A · День 1

Сайт-инструкция для тренировки в зале: техника, схемы движений, ошибки, выбор веса,
замены упражнений, таймер отдыха и трекер подходов. Открывается с телефона, работает офлайн
после первой загрузки, ничего не нужно устанавливать.

## Что внутри

- 7 упражнений, у каждого отдельный экран: старт/финиш схемой, мышцы, пошаговая техника,
  частые ошибки, признаки слишком большого веса, дыхание, темп, замены и подсказка «Думай о…»
- Разминка и заминка
- Правило RIR и система прогрессии
- Таблица замен «если тренажёр занят»
- Трекер: веса, повторения, RIR, комментарии — сохраняются в браузере
- Таймер отдыха с сигналом и вибрацией
- Тёмная и светлая темы

## Структура

```
index.html              оболочка: шапка, контейнер, панель таймера
manifest.webmanifest    установка на главный экран телефона
favicon.svg
css/style.css           вёрстка, темы, стили схем
js/figures.js           векторные схемы техники + карта мышц (нарисованы вручную)
js/data.js              всё содержание тренировки
js/app.js               роутер, экраны, состояние, таймер
trenirovka_A_den_1_prompt.md   ТЗ и полное содержание тренировки текстом
```

Никаких зависимостей, сборки и бэкенда — только HTML, CSS и обычный JS.

## Запуск локально

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## Публикация на GitHub Pages

1. Запушить репозиторий в `main`.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу вида
   `https://<username>.github.io/fit/`.

## Как изменить тренировку

Всё содержание лежит в `js/data.js`: упражнения, подходы, техника, ошибки, замены.
Схемы движений — в `js/figures.js`, каждая схема это функция из простых примитивов
(`F.limb`, `F.spine`, `F.head`, `F.arrow`). Разметку и логику трогать не нужно.

## Важно

Материал — тренировочная инструкция, а не медицинская рекомендация и не диагноз.
Не работать через боль; при повторяющихся симптомах обратиться к врачу
или квалифицированному физиотерапевту.
